OCR 图片识别

OCR 图片转文字

截图里的文字，也能整理进笔记。选好区域后使用 OCR，减少手动录入。

下载 Windows 版返回首页 →

如何识别

  1. 启动截图并选择包含文字的区域。
  2. 在截图工具栏或贴图操作中选择文字识别。
  3. 等待结果后复制文字，整理进便签或其他文档。

使用前了解

OCR 需要联网，选取的图片会发送至百度 OCR 服务进行处理。识别效果受文字清晰度和图片内容影响，请核对结果。

继续处理截图

你也可以标注、复制、贴到桌面或插入便签，让文字和图片留在一起。
