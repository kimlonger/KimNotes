截图与贴图

截图贴图

把需要参考的画面留在桌面，边看边做，不用在窗口之间来回切换。

下载 Windows 版返回首页 →

从截图到贴图

  1. 从便签或托盘启动截图，拖动鼠标选择需要的区域；选区可以移动和调整。
  2. 使用工具栏进行标注，确认后复制并贴到桌面。
  3. 移动或缩放贴图，需要时通过右键操作关闭或销毁。

把最近贴图找回来

在设置里可以查看和修改唤回、上一张、下一张的快捷键；贴图右键菜单也提供切换入口。贴图历史保存在本机。

截图也能放进便签

选择插入便签后，图片会放到最近打开的便签末尾；没有打开的便签时会新建一张。
