待办与提醒

桌面待办提醒

把要做的事列下来，在合适的时间提醒自己。

下载 Windows 版返回首页 →

添加待办

  1. 打开待办清单，选择“新增”。
  2. 填写内容，选择提醒时间；也可以先不设置提醒。
  3. 需要循环时，选择每天、工作日或每周重复。

提醒方式

到点后弹窗提醒；在设置中可选择仅弹窗或弹窗加铃声。提醒依赖程序运行，待办保存在本机。

和便签一起使用

选中便签中的文字可以转为待办；原有便签内容仍然保留。
