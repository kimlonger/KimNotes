Windows 桌面便签 · 截图标注 · 解压即用免安装

随手记便签，顺手标截图

小羊便签把「桌面便签」和「截图标注」两件事合进一个免安装的小程序：贴几张便签在桌面随时改，按一次热键框选截图，矩形、箭头、马赛克、文字当场标完，需要文字就顺手 OCR 成可编辑内容。

下载 Windows 版 v1.3.7 先看截图怎么用

v1.3.7 · Windows 10 / 11 · Apache-2.0 开源 · 无广告、无账号，便签和待办本地保存

它管这六件事

没有账号体系，没有云同步，不装任何系统服务。窗口全关掉只是缩回托盘待命，托盘里点「退出」才结束进程。

便签

无边框便签卡片

边缘可拖拽拉伸，一键置顶。正文支持项目符号、加粗、图片和文字翻译。失焦且鼠标离开连续 5 秒后，两栏约用 0.7 秒渐隐；点击便签渐显，正文不会占用两栏空间。

截图

全局热键区域截图

Ctrl + 一个键唤起全屏框选，松手即成置顶贴图，并自动展开一次操作菜单。可插入便签、复制、另存、拾色；支持滚轮缩放和拖动查看，之后仍可右键打开菜单。

标注

四种画笔当场标

矩形、箭头、马赛克、文字。图标采用统一的矢量网格，工具条和截图共用窗体；大图自动缩小显示并留出工具条空间，输出保留原始分辨率。Ctrl+Z 撤销上一笔。

识别

OCR 转文字 + 中英互译

截图菜单点 OCR，识别结果新建便签并复制到剪贴板；划选正文点翻译，中文翻英文、其他语言翻中文。官方包内置百度应用配置，无需填写凭证；两项功能按需联网。

待办

划选转待办 + 定时提醒

选中文字可转待办。清单和新增窗口默认都是窄版竖向卡片，可手动拉伸；提醒预设两列两行，支持直接输入日期、日历选日和快捷时间列表。到点弹置顶小窗，默认仅弹窗，可开启铃声。

外观

每张便签独立配色

8 套主题按便签单独选择并保存，便签列表显示各自颜色。无痕模式下便签、配色、待办和提醒记录仅留在内存，适合临时使用。

截图到标注，两步不出窗

按热键框选 → 自动展开操作菜单 → 选择标注或插入便签。选「插入便签」会追加到最近打开且仍未关闭的便签正文底部，没有便签打开时才新建；图片随便签保存。

便签和待办保存在本机

便签和待办无需账号、保存在本机。正文、配置和 JSON 保存使用临时文件原子替换，覆盖时保留上一份 .bak；损坏数据尽量从有效备份恢复，并保留损坏原文件。

位置存了什么
%AppData%\KimNotes\config.txt配置：截图热键、应用默认主题、笔记与截图目录、开机启动、无痕模式和提醒方式
%AppData%\KimNotes\notes\默认便签目录：RTF 正文与每张便签的 .rtf.meta.json 配色文件，插入的图片保存在正文内
%AppData%\KimNotes\images\双击贴图时的默认保存目录，可在设置的「截图位置」修改；菜单「另存」可另选位置
%AppData%\KimNotes\index.json便签列表的搜索索引，未改动的便签不重复解析
%AppData%\KimNotes\todos.json待办清单，独立于便签正文
%AppData%\KimNotes\reminders-fired.json提醒去重记录，避免同一条待办反复弹

笔记和截图目录可在设置中修改。OCR 与翻译使用百度在线服务：只有主动使用时，才会发送当前图片或相关文字。官方发行包内置作者的百度应用配置，设置中没有凭证入口。

常见问题

还有问题看仓库 README，或直接开 issue。

小羊便签免费吗？

免费。采用 Apache License 2.0 开源协议，可以免费使用、修改和再分发。

需要安装吗？

不需要安装，下载 zip 解压后双击 KimNotes.exe 即可运行（包里只有一个依赖 dll：Newtonsoft.Json.dll，要和 exe 放在一起）。程序基于 .NET Framework 4.8，Windows 10 与 Windows 11 通常已自带；若提示缺少运行库，安装一次 .NET Framework 4.8 即可。

便签内容和截图存在哪里？

默认存在本机 %AppData%\KimNotes\：便签正文与配色在 notes\，待办在 todos.json。双击贴图会保存到设置的截图目录（默认 images\）并关闭，菜单「另存」可选择其他位置。笔记和截图目录可以在设置中修改，插入便签的图片随 RTF 正文保存。

会把我的笔记上传到云端吗？

不会。程序没有账号、没有云同步。只有在你主动点 OCR 或翻译时，才会把当前图片或选中文字发给百度开放平台的识别与翻译接口。

截图怎么插进现有便签？

截屏完成后会自动展开一次操作菜单，点「插入便签」追加到最近打开且仍未关闭的便签正文底部；没有任何便签打开时才新建。便签中也支持 Ctrl+V 在光标处粘贴剪贴板图片。

OCR 和翻译需要配置密钥吗？

官方发行包已内置作者的百度应用配置，设置里没有凭证入口，直接使用即可。两项功能需要网络连接及百度服务正常响应。从公开源码自行构建时，需要开发者自行提供应用配置。

截图热键怎么改？

设置页的「快捷键」里，Ctrl 固定不变，点一下键帽再按任意一个键即可换键，默认是 Ctrl + F1。如果提示注册失败，说明这个组合被别的程序占了，换一个即可。

无痕模式是干什么的？

开启后启动不恢复上次便签，便签、配色、待办和提醒记录只留在内存，截图双击直接关闭。配置设置仍会保存；手动另存截图仍是保存操作；OCR 与翻译仍需联网。

怎么退出？托盘图标在哪？

托盘里那只小羊就是：右键弹菜单 新建便签 / 便签列表 / 待办清单 / 设置 / 退出，左键单击唤回已开的便签窗。窗口全关掉不会结束进程，只有点菜单里的「退出」才真正退出。Windows 11 上新出现的托盘图标默认缩在任务栏的 ^ 溢出区，拖到可见区即可常驻。

高分屏上字会不会糊或被切？

窗体和控件按 DPI 缩放，图标已检查多种渲染尺寸。不同缩放的多屏切换仍需实机验证；如果遇到布局异常，可附系统缩放比例与截图到仓库反馈。
