使用指南

下载并解压整个 ZIP，双击 KimNotes.exe，即可从系统托盘新建便签。便签自动保存在本机，登录后可同步。

适用于 Windows 10 / 11，需要 .NET Framework 4.8。便签默认保存在 %AppData%\KimNotes，可在设置中更改保存目录。
