第一次使用？从这里开始。使用指南

  1. 下载并解压

    下载完整安装包，解压到任意文件夹，保留随包文件。

  2. 打开 KimNotes.exe

    双击运行，从任务栏右下角的小羊托盘图标新建便签。

  3. 随手记录，自动保存

    本机内容自动保存。在设置中登录账号，便签与图片会继续同步到云端。

需要安装吗？

下载解压即可使用。需要 .NET Framework 4.8，Windows 10 / 11 通常已自带。

内容保存在哪里？

默认保存在本机 %AppData%\KimNotes，位置可在设置中修改。登录后自动同步，离线时也能继续记录。

下载遇到问题？

当前下载版本 v1.4.18。可以使用 GitHub 备用下载，或查看更新说明。
