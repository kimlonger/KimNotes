v1.4.22 2026-11-23

  • 登录桌面版后同步待办，可在网页版查看并搜索。
  • 注册便签账号时填写昵称并选择头像，已有用户可在网页版编辑便签资料。
  • 设置页右侧显示头像和登录状态，应用常用开关排列在左侧。
  • 修复网页版切换便签筛选时的横向跳动，官网「帮助」提供 QQ 交流群入口。
  • 精简桌面托盘菜单，贴图可继续使用快捷键，账号入口位于设置。

本次更新沿用 1.4.22。已在使用 1.4.22 的用户需重新下载安装包。

v1.4.21 2026-11-23

  • 修复 Windows 11 拼音尚未选词时，自动保存提前结束组词、将拼音写入正文的问题。
  • 组词期间暂缓自动保存和云同步，完成选词后继续保存与同步。
  • 修复便签、设置等窗口标题栏图标显示为彩色噪点。
  • 修正发布包的运行时目标标记，解决桌面登录、同步和检查更新的 HTTPS 连接失败。
  • 便签列表统一搜索框与卡片的圆角描边，修复横向拉伸残影。
  • 待办清单采用统一标题栏，修复左右拉伸的残影和滚动条闪现。右键已完成的待办可删除，原记录保留在本机。

已更新同版本发布包。已使用早期 1.4.21 时请重新下载，版本号相同不会再次弹出更新通知。
