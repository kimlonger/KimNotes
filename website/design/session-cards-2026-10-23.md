# 官网会话与便签卡片实施记录 · 2026-10-23

实现及主线程验收已完成，正式发布结果见 `../../docs/session-release-2026-10-23.md`。以下保留开发阶段的实现说明。

- 保留原生官网字体、图标、浅蓝强调与便签主题色，改为左侧「全部 / 含图片 / 最近删除」、主题色竖向卡片总览、560px 阅读抽屉。1640px 及以上 4 列，常见桌面 3 列，中小屏 2 列，极窄屏 1 列；手机阅读全屏。
- 阅读用原生 dialog 管理焦点与 Escape；关闭恢复卡片焦点，支持展开阅读。搜索、正文复制、历史、编辑、软删除及恢复沿用现有 API。桌面 rtf / rtfGzip 保持只读；修复纯图片便签复制正文时访问空列表的问题。
- 私有缩略图由 IntersectionObserver 懒加载，携带同源 Cookie、预期账号头。临时 Blob URL 在重绘、关闭阅读、历史切换、离开页面时撤销，未完成加载可取消。
- 网页文案切换为 30 分钟无操作 / 8 小时绝对期限。activity 与每 30 秒同步完全分离，只对最近的真实交互节流上报；后台计时、合成事件、隐藏页面不会上报。真正期限由后端实施。
- 过期先保存当前标签页、当前账号的草稿和原始重试 operationId，关闭私有内容。重新登录相同账号才恢复，用户确认保存后才上传。换账号不恢复；存储配额/隐私限制导致暂存失败时展示可复制内容。
- 登录设备支持 GET sessions、DELETE 单设备、logout-all，所有变更需产品内确认。支持 ?panel=devices。改密前保护草稿；跨标签页账号变化会锁定页面并重载。
- JSON API 携带 X-Kim-Auth-Version: 2 和 X-Kim-Expected-User；Worker 同时转发。后端需将预期账号不符拒绝为 409 account_changed。Worker 配置不再覆盖为 sessionLifetimeDays:30，保留 Go 的网页与桌面时长。

验证：Node 24.16，`npm test` 共 31 项通过；包含 18 项原网关/验证码/认证回归，5 项主动活跃/草稿隔离策略，8 项 jsdom 真 DOM 行为。额外执行 JS 语法检查。所有账号、便签、图片响应均为合成 fixture；没有使用生产账号或访问私有便签。

主线程已使用真实浏览器检查桌面、390px 手机卡片与全屏阅读，并在正式域名打开卡片与阅读抽屉。正式效果截图为 `../../docs/cloud/notes-cards-20261023.png`。另外修复阅读双滚动条、手机阅读右侧空隙，手机卡片正文提高为 12px。没有把 jsdom 当作视觉验收。
