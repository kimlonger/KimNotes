# 官网便签的时间分组

默认按月，可切换为按周、按年，选择仅在浏览器保存。周一为一周起点，
按浏览器所在时区划分自然周、月、年。各组、组内便签均按最近内容编辑时间
从新到旧排列；分组可折叠，搜索直接显示所有匹配结果。

昨天创建、今天编辑的便签归入今天所在的组，不重复展示；创建时间保持不变。
详情同时显示创建时间、最近编辑时间。最近删除视图按删除时间排列和分组。

## 内容时间

`document.contentUpdatedAt` 是独立的 UTC 时间，由后端写入当前 JSON 文档和
同步快照，无数据库结构迁移。旧桌面客户端无需发送或理解此字段。

- 新建、修改标题或正文、文字格式、增删图片、调整图片大小时更新。
- 单独修改主题、重复上传相同文档、删除和恢复时保留。
- 图片模板中重新生成的标记 UUID 和 RTF 压缩编码变化不算内容编辑。
- 客户端提交的该字段由服务器重新计算，避免客户端遗漏或错误值覆盖。
- 查看、下载、拖动窗口不会改变服务器的内容时间。

旧文档没有独立内容时间时，沿用原有 `updatedAt`；首次收到未修改内容的
写入时将该时间固定下来。已有数据无法准确区分过去的主题变更与内容编辑，
不推测或伪造过去的时间。新字段仍采用服务器接收内容变更的时间；原有
`createdAt` 仍是云端首次创建时间，桌面离线编辑的真实发生时间与首次上传前的
本机创建时间迁移，不属于本次官网分组改动。

## 验证

- 网页测试覆盖分组切换和记忆、折叠、搜索、内容编辑跨组、主题不跨组、
  创建时间保留、跨月跨年、当地时区、夏令时和旧数据回退。
- Go 单元测试覆盖服务端内容时间、旧客户端、压缩 RTF、图片标记及尺寸变化。
- `TestContentTimeAPIPersistence` 在配置独立测试数据库时验证保存、删除恢复
  和新设备 bootstrap；没有测试数据库时明确跳过。
