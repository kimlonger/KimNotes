# 小羊便签 KimNotes v1.4.21

修复 Windows 11 拼音输入和窗口重绘问题，优化便签列表与待办清单。

## 本次更新

- 拼音组词期间暂缓自动保存，避免 RichEdit 导出文档时提前结束组词。
- 云同步等待当前组词完成，不读取或替换尚未确认的输入内容。
- 完成选词后重新计算空闲保存时间，继续保存和同步；主动关闭窗口时正常结束输入并保存。
- 修复便签、设置等窗口标题栏的小羊图标显示为彩色噪点的问题。
- 修正发布 EXE 遗漏的 .NET Framework 4.8 目标标记，解决新启动时桌面登录、云同步和检查更新无法建立 HTTPS 连接的问题；OCR 不再改写全局连接协议。

- 便签列表移除标题栏设置按钮，搜索框和历史卡片采用圆角描边，修复横向拉伸残影。
- 待办清单使用带小羊图标的统一标题栏，修复横向拉伸残影和滚动条闪现。
- 右键已完成的待办即可删除。列表和搜索隐藏该条待办，原文、来源和完成时间仍保存在本机。

## 验证

在原版 1.4.20 上记录到：输入法开始组词后，自动保存发送 `EM_STREAMOUT`，紧接着收到 `WM_IME_ENDCOMPOSITION`，尚未选词的拼音被提交到正文。

前一轮拼音与图标修复通过 427 项桌面回归、26 项同步策略检查、75 项云同步检查和 12 项同步边界检查。覆盖未选词时超过保存时限、原生 `Modified` 尚未触发 `TextChanged`、同步暂缓与恢复、选词后保存，以及取消未改动的组词。用户已验证修复测试包的实际输入效果；正式构建将程序版本更新为 1.4.21。本次对最终 ZIP 追加 7 项网络检查，不启动桌面窗口或浏览器。

图标回归在原始发布包上复现失败、在修复构建及最终 ZIP 解压出的 EXE 上通过。直接解码 ICO 中的 PNG 作为像素参照，核验便签、历史、设置、注册窗口资源及便签实际标题栏；检查 100%、125%、150%、200% 图标尺寸与窗口截图。

本次替换包通过便签列表与待办清单的圆角、尺寸、跨屏、滚轮、删除及重启验收，并通过发布包的 7 项 HTTPS 和客户端网络检查。

发布包网络验收：`tests/run-release-network.ps1 -Executable <最终解压的 KimNotes.exe> -Online`。检查实际 EXE 的目标框架及配套配置，在相同兼容级别的全新应用域中调用发布包原有的更新与账号客户端；只提交空登录字段来验证接口可达性，不使用真实账号、密码或便签。普通桌面测试默认执行框架标记与 HTTPS 默认配置检查，发布前追加在线验收，避免测试进程自身的 .NET 4.8 标记掩盖发布包遗漏。
