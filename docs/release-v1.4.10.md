# 小羊便签 KimNotes v1.4.10

适用于 Windows 10 / 11 的免费开源桌面便签、截图贴图和待办提醒工具。发布日期：2026-10-19。

## 新增与改进

- **桌面布局与自动保存**：恢复已保存便签的打开状态、位置、大小、所在屏幕和置顶状态；输入后显示保存结果，失败时保留正文并重试。
- **便签内图片操作**：双击查看大图，右键复制、另存、缩放、适应宽度或删除单张图片，保留周围正文。
- **周期提醒**：支持每天、工作日和每周重复；启动、唤醒和解锁后检查，错过多期合并为最近一期，同一期避免重复弹出。
- **贴图历史**：关闭后可唤回最近一张，在同一浮窗查看上一张 / 下一张。默认 `Ctrl+F2` 唤回、`Ctrl+←` 上一张、`Ctrl+→` 下一张，均可修改并检查冲突。
- **截图流程**：框选后显示单行紧凑工具栏，选区可移动、调整边角；绿色对勾合并标注、复制图片并保留贴图。工具栏与右键菜单都可使用。
- **紧凑界面**：缩小设置和待办编辑窗，统一字号与字段宽度；托盘使用简洁普通菜单。

## 修复与行为说明

- 修复截图首次点击工具闪烁、局部遮罩变暗，以及截图结束后访问已释放 `ScreenOverlay` 的异常。
- 改进跨屏布局与窗口刷新，快捷键录入支持左右方向键。
- **关闭贴图**：右键「关闭贴图」、工具栏关闭按钮或 Esc，关闭浮窗并保留历史，可再次唤回。
- **销毁贴图**：独立右键操作，删除当前图片的历史缓存和备份，不能再唤回；不会删除用户手动另存的图片。同图其他浮窗同步关闭，避免历史被重新保存。
- 去掉贴图右上角 ×，图片上不叠加关闭按钮。

## 下载与升级

下载本页的 `KimNotes-v1.4.10.zip`，完整解压后运行 `KimNotes.exe`，保留同目录配置和 DLL。升级前先从托盘退出旧版，正常升级继续使用原数据目录；建议保留数据备份。需要 .NET Framework 4.8。

便签和待办无需账号、保存在本机。官方发行包内置作者的百度服务配置，OCR 和翻译按需联网；公开源码不包含服务密钥。
