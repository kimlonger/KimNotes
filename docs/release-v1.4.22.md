# 小羊便签 KimNotes v1.4.22

## 本次更新

- 登录 Windows 版后，待办会从本机同步到账号。网页版支持查看和搜索待办，编辑、删除和提醒仍由桌面版处理。
- 新用户注册时填写昵称并选择头像。已有账号使用默认便签资料，可在网页版修改。
- 设置页右侧显示头像和登录状态，左侧保留常用开关。
- 网页版便签筛选切换时保持布局稳定，移除积分入口，官网「帮助」提供 QQ 交流群入口。

- 精简桌面托盘菜单，贴图可继续使用快捷键，账号入口位于设置。
