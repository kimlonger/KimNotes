# 小羊便签 KimNotes v1.4.18

适用于 Windows 10 / 11 的免费开源桌面便签、截图贴图与待办提醒工具。
本版将此前开发版的账号、云同步和桌面修复合并为正式发布版。

## 本次更新

- 桌面加入账号登录，与官网共用邮箱和密码；注册入口在系统浏览器打开官网，
  EXE 登录无需人机验证。登录后自动双向同步便签及图片，新电脑可以下载到本地。
- 离线先保存本机，联网后继续同步。输入停顿约 2 秒保存，连续输入最长约 5 秒
  尝试保存；本地保存后约 10 秒发起上传，持续编辑最长等待约 60 秒，空闲时
  约每 60 秒检查云端变化。登录、启动和手动同步立即检查。
- 新电脑首次登录直接下载最新便签，随后接收增量变化，下载中断可续传。
  未修改的便签不反复重写同步索引；新建空白便签不上传，已同步便签清空后同步清空。
- 优化主副屏移动、贴图缩放清晰度和残影；便签内图片支持复制、查看、拖拽及滚轮
  缩放，图片字节与周围正文保持完整；便签中的网址可以打开浏览器。
- 修复主题切换时标题、图标和按钮配色不一致，以及新建窗口组件分批出现的问题。
  设置入口统一为「账号」，默认便签尺寸与紧凑工具栏协调。
- 官网和云端便签页改为简洁的白色布局，支持按最近内容编辑时间的周、月、年
  分组、搜索及阅读；保留 LINUX DO 社区链接和最近删除恢复。

## 下载与升级

下载 `KimNotes-v1.4.18.zip`，完整解压后运行 `KimNotes.exe`，保留同目录的
`KimNotes.exe.config`、`Newtonsoft.Json.dll` 和说明文件。需要 .NET Framework 4.8，
Windows 10 / 11 通常已自带，无需 WebView2。

升级前从托盘退出旧版，再运行新版本；正常升级沿用原有数据目录和登录状态。
桌面便签可离线使用，登录为可选操作。待办和贴图历史目前仍为本机数据。
云端富文本便签在网页只读，在桌面编辑以保留格式。OCR 和翻译使用百度在线服务。

客户端使用域名接口，服务器密钥不进入安装包；本机登录凭证由 Windows DPAPI
加密，密码不落盘。网页登录采用 30 分钟空闲 / 8 小时绝对有效期，桌面自动续期。
