# 文件互传配对服务

在 `backend` 目录运行 `go run ./cmd/file-transfer-rendezvous -listen 0.0.0.0:43763`。跨网模式需要两端可访问服务的 IPv4 UDP 端口。预览可在两端设置 `KIMNOTES_P2P_SERVER` 为配对地址，例如 `127.0.0.1:43763`。

配对请求使用 LiteNetLib 的无连接消息，服务只交换经地址确认的两端 UDP 地址。等待中的配对最长保留三分钟，两个设备建立连接后直接传文件。服务的房间状态只保存在内存中。

新版客户端可以附带最多四个本地或 IPv6 直连地址。地址以逗号分隔，只接受 RFC 1918 私有 IPv4 和 `2000::/3` IPv6，加上非零端口。经过确认的双方都附带地址时，服务会在配对响应末尾附带对方的地址列表。旧客户端继续收到原有的 IPv4 配对响应。
